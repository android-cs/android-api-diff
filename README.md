# android-api-diff

**<https://diff.songe.li>**

An online tool to show Android Java/AIDL files api changes between different android inner versions

## CLI + Agent Skill

Install or upgrade the CLI and install its Codex Skill globally:

```sh
npx android-api-diff@latest install
```

The command delegates CLI upgrades to npm and installs the Skill version that
matches the published CLI. Project-scoped installation and recovery commands
are documented in the CLI guide.

[CLI usage, Skill setup, and MCP migration guide](./CLI.md)
